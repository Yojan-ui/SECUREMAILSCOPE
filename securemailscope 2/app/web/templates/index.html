What gets checked

DMARC
Whether the policy actually enforces. p=none reports forgery and delivers it anyway, which is the most common failure we find.
SPF
Record validity, the terminal all qualifier, and the 10-lookup limit counted by resolving the real include: chain.
DKIM
Selector discovery across the major mail platforms, with each public key decoded so the true key size is measured rather than guessed.
Transport
MX discovery, STARTTLS, which TLS versions each host will accept, cipher suites, and certificate chain and expiry.
Policy
MTA-STS, including a fetch of the hosted policy file rather than trusting the DNS record alone, plus TLS-RPT and BIMI.
